# Manaíra Board V74.9 — DANFE em layout NF-e clássico

## O que mudou
- a DANFE foi redesenhada para ficar mais próxima do layout tradicional de NF-e;
- foi adicionada a faixa superior de recebimento/assinatura;
- o cabeçalho agora fica no estilo clássico: emitente à esquerda, DANFE no centro e chave de acesso com código de barras à direita;
- foram mantidas as informações extras da versão anterior:
  - código de barras/chave de acesso;
  - detalhes fiscais adicionais por item (EAN, unidade tributável, ICMS, IPI, PIS e COFINS);
  - dados adicionais no final;
  - paginação corrigida.

## Observações
- o documento continua sendo gerado a partir do XML integral da NF-e;
- o layout foi aproximado ao modelo clássico, mas ainda deve ser validado com notas reais do setor;
- a linha do código de barras/chave foi preservada conforme solicitado.
